03 / BOUNDARY

Flask remains separate.

HTTP requests never import PyTorch or XGBoost. The web process writes jobs. Companion workers bridge those jobs to the unchanged Kafka topics.

Model interpretation

Scores, not verdicts.

Both values are model-estimated suspicious-play scores from zero to one. There is no probability-calibration stage, and the interface never labels a player a cheater.

Recovery

Replay is ordinary.

Leases recover abandoned jobs. Stable game IDs and unique result rows make a repeated Kafka message safe. SSE resumes from its last durable event ID.
