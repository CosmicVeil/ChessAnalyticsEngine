Information / how it works

About Chess Analytics Engine

Chess Analytics Engine turns complete PGN game collections into game-level signals. It extracts board features, scores them with isolated PyTorch and XGBoost workers, and streams durable updates back to the browser.

⌁

01 / Analyze

What the site does

Upload a PGN or paste one or more games. The engine preserves their source order, extracts game-level features, and evaluates each game with both models.

  • Game-level feature extraction
  • Dual-model scoring
  • Results filtering
)))

02 / Stream

How live updates work

Isolated workers process games in the background. Durable server events update the ledger as results arrive, without requiring a page reload.

  • Background processing
  • Streamed updates
  • Replay-safe events
!

03 / Interpret

Important note

Model scores are not calibrated probabilities and do not prove cheating. They are heuristic signals intended to support careful human review and investigation.

  • Not probabilities
  • Not proof of cheating
  • Use human judgment
